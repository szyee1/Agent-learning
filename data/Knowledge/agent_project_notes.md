# Agent Demo 项目说明

## 当前实现

项目使用 Python 调用大语言模型 API。
Agent 支持多轮对话和工具调用。
已实现 calculate 和 get_current_time 两个工具。

## 对话管理

项目支持保存和加载对话历史。
通过上下文裁剪控制输入消息的长度。
使用摘要机制保留较早对话中的关键信息。

## 调试与评测

项目记录 Agent 的运行轨迹。
评测脚本可以测试工具选择和最终回答。
目前评测用例数量较少，需要继续补充。

## 后续计划

增加本地知识库读取能力。
进一步实现文档检索和知识库问答。
完善异常处理、自动化测试和运行日志。
