# Agent Demo 项目说明

## 一、当前已实现功能

### 1. Agent 基础能力

* 使用 Python 调用大语言模型 API。
* 支持多轮对话和工具调用。
* 支持多轮工具执行，将工具结果返回模型并生成最终回答。
* 支持会话重置、退出等交互操作。

### 2. 工具调用

- `calculate`：执行数学计算。
- `get_current_time`：获取当前时间。
- `list_knowledge_files`：列出知识库中的 Markdown 和 TXT 文件。
- `read_knowledge_file`：读取指定的知识库文档。
- `search_knowledge`：使用 BM25 进行关键词检索。
- `search_knowledge_embedding`：使用 Embedding 向量相似度进行语义检索。

### 3. 对话管理与记忆

* 保存和加载对话历史。
* 根据轮数和 Token 预算裁剪上下文。
* 使用摘要机制保留较早对话中的关键信息。
* 支持重置对话历史和摘要状态。

### 4. 知识库处理

- 从本地目录加载 Markdown 和 TXT 文档。
- 将文档切分成较小的文本块。
- 使用 jieba 对中文查询和文档进行分词。
- 使用 BM25Okapi 进行关键词检索。
- 使用 BAAI/bge-small-zh-v1.5 将查询和文档转换为向量。
- 通过向量相似度进行语义检索。
- 根据相关性分数排序，返回 Top-K 文本块。
- 将检索结果交给大语言模型生成回答。

目前已经实现 BM25 关键词检索和 Embedding 语义检索。
两种检索方式均可通过 Agent 工具调用。
混合检索 RRF 目前用于离线实验，尚未接入 Agent 的默认检索流程。

### 5. 调试与评测

* 记录 Agent 的运行轨迹。
* 统计上下文消息数量及 Token 使用情况。
* 通过测试用例检查工具调用和最终回答。
* 初步比较不同上下文管理策略的效果。

## 二、当前局限

- BM25 对同义表达和语义差异较大的查询支持有限。
- Embedding 检索的效果仍需要在更大、更有代表性的测试集上验证。
- BM25 与 Embedding 的自动选择和融合策略仍需优化。
- 当前检索评测用例数量较少，测试覆盖不足。
- 仍需进一步完善异常处理、调用失败处理和运行监控。

## 三、后续开发计划

* 优化文本切分、检索排序和结果筛选。
* 增加检索准确性、召回率等指标的评测。
* 完善工具调用限制、异常处理和自动化测试。
* 增加 API 接口和简单的 Web 交互界面。
* 进一步完善 Agent 的工程化能力。

## 四、项目目标

逐步构建一个具备工具调用、上下文管理、摘要记忆和知识库问答能力的 Agent 应用，通过可复现的测试验证功能和优化效果。
